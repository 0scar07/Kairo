Qué es Kairo

Kairo es una app móvil gratuita que muestra estadísticas públicas de League of Legends y Teamfight Tactics a partir de la API oficial de Riot Games y, opcionalmente, de Brawl Stars, Clash Royale y Clash of Clans a partir de las APIs oficiales de Supercell.

Qué datos se guardan y dónde

  • En tu dispositivo (no salen de él): tus jugadores favoritos, tus búsquedas recientes, tu región, tu juego activo, tu Riot ID de "Mi perfil" y tus preferencias (por ejemplo, la vibración).
  • En nuestro servidor: no guardamos cuentas, contraseñas ni datos personales. El servidor mantiene una caché temporal en memoria de respuestas públicas de Riot (de 1 minuto a 1 hora) para reducir llamadas, y se vacía al reiniciarse.
  • Registros técnicos: el servidor registra método, ruta, código de estado y duración de cada petición. Los nombres de jugador y los identificadores largos (como el PUUID) se enmascaran: no se registran.

Qué no hacemos

  • No pedimos ni almacenamos tu contraseña de Riot ni usamos Riot Sign On.
  • No vendemos, alquilamos ni compartimos datos con terceros.
  • No mostramos anuncios ni usamos analítica de seguimiento.
  • Solo mostramos datos públicos de partidas ya terminadas; no ofrecemos información en tiempo real de una partida en curso.

Servicios de terceros

La app consulta la API de Riot Games (a través de nuestro servidor) y el CDN público Data Dragon de Riot para imágenes. Se aplican las políticas de Riot Games a esos datos.

Para Brawl Stars, Clash Royale y Clash of Clans, nuestro servidor consulta las APIs de Supercell a través de un proxy comunitario (RoyaleAPI), que reenvía la petición con el tag del jugador buscado; las imágenes de Brawl Stars se descargan del CDN público de Brawlify. No se comparte ningún dato personal con ellos. Se aplican las políticas de Supercell a esos datos.

Cómo borrar tus datos

Todo lo que guarda la app está en tu dispositivo: en Ajustes puedes borrar las búsquedas recientes, y al desinstalar la app se elimina el resto.

Menores

Kairo no recopila datos personales de ningún usuario, incluidos los menores.

English

What Kairo is

Kairo is a free mobile app that shows public League of Legends and Teamfight Tactics stats using Riot Games' official API and, optionally, Brawl Stars, Clash Royale and Clash of Clans stats using Supercell's official APIs.

What data is stored and where

  • On your device (it never leaves it): your favorite players, recent searches, region, active game, your "My profile" Riot ID and preferences (such as haptics).
  • On our server: we store no accounts, passwords or personal data. The server keeps a temporary in-memory cache of public Riot responses (1 minute to 1 hour) to reduce API calls; it is cleared on restart.
  • Technical logs: the server logs the method, path, status code and duration of each request. Player names and long identifiers (such as PUUIDs) are masked, so they are not logged.

What we don't do

  • We don't ask for or store your Riot password, and we don't use Riot Sign On.
  • We don't sell, rent or share data with third parties.
  • We show no ads and use no tracking analytics.
  • We only show public data from finished matches; we provide no real-time information about a game in progress.

Third-party services

The app queries the Riot Games API (through our server) and Riot's public Data Dragon CDN for images. Riot Games' policies apply to that data.

For Brawl Stars, Clash Royale and Clash of Clans, our server queries Supercell's APIs through a community proxy (RoyaleAPI), which forwards the request with the searched player's tag; Brawl Stars images are downloaded from Brawlify's public CDN. No personal data is shared with them. Supercell's policies apply to that data.

How to delete your data

Everything the app stores is on your device: in Settings you can clear recent searches, and uninstalling the app removes the rest.

Children

Kairo collects no personal data from any user, including minors.
